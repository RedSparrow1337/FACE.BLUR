# Faceblur (SPT 4.1.6) 
What the mod does
• Flat pixel mosaic. A square made of large blocks that always faces the camera and has no depth.

• Blocks adjust based on distance. The mosaic is coarse up close but remains legible from afar.

• Colors are sampled from the scene. The blocks average out the colors beneath them—skin, helmets, balaclavas, shadows.

• Attached to the head. It moves, falls, and turns along with the character.

• Remains on the corpse. The mask is bound to the head bone and does not come off upon death.

• Your character remains unaffected.

# In-game settings (F12 → Faceblur)
Each bot type can be toggled individually:
• AI PMCs (USEC/BEAR)

• Scavs

• Bosses

• Boss guards

• Raiders and Rogues

• Others (Cultists, etc.)

Plus a master toggle. You can also adjust the square size, block coarseness, and the mask's offset (up, forward, and right).

# Installation
1. Copy the Faceblur folder (containing Faceblur.dll and faceblur.bundle) to SPT\BepInEx\plugins\.
2. Launch the game. Settings can be accessed via F12 (requires BepInEx Configuration Manager).

Uninstallation:
Simply delete the Faceblur folder.

# Compatibility and Limitations
• SPT 4.1.6 only; other versions have not been tested.

• positioning may not be perfect at very long distances or extreme viewing angles.
